# CheckMiss

院内记录与网报卡辅助核查工具。

本项目用于对院内导出的诊疗记录和网报卡数据进行批量核对，辅助发现可能需要进一步人工复核的记录。程序以 CSV 文件为主要输入，重点处理姓名、证件号、诊断文本、报告时间、复诊周期、候选卡排序等问题。

## 主要能力

- 对院内诊疗记录进行规则筛选，输出筛选后文件。
- 按姓名和证件号匹配网报卡，支持中文姓名后缀兼容。
- 按疾病信号拆分主结果，便于处理一条记录包含多个病种提示的情况。
- 根据候选卡关系、报告时间和复诊周期生成辅助判定。
- 输出已报告/合规候选、可疑漏报、候选卡明细和文本统计报告。
- 提供独立依赖卸载工具，便于用户在 Python 环境异常时重装依赖。

## 文件说明

- `CheckMiss-v10.1.6.py`：当前推荐版本。
- `CheckMiss-v10.1.2.py` 至 `CheckMiss-v10.1.5.py`：近期迭代版本，保留用于追溯。

## 输入文件

程序运行时会提示选择或读取 CSV 文件。常用字段包括：

- 院内记录：`姓名`、`身份证`、`诊断`、`就诊时间`
- 网报卡：`患者姓名`、`有效证件号`、`疾病名称`、`报告卡录入时间`、`卡片ID`

请勿提交真实业务数据到公开仓库。

## 运行方式

安装 Python 后，运行当前推荐版本：

```bash
python CheckMiss-v10.1.6.py
```

首次运行会检查依赖库，并提示选择安装源。
