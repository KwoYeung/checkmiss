# CheckMiss

院内记录与网报卡辅助核查工具，可直接用 Python 运行。

## 下载与运行

普通用户建议从 Releases 下载最新 `.py` 文件：

- GitHub Releases: <https://github.com/KwoYeung/checkmiss/releases>

运行方式：

```bash
python CheckMiss-v10.1.6.py
```

首次运行会检查依赖库，并按提示选择安装源。

## 输入文件

常用字段包括：

- 院内记录：`姓名`、`身份证`、`诊断`、`就诊时间`
- 网报卡：`患者姓名`、`有效证件号`、`疾病名称`、`报告卡录入时间`、`卡片ID`

请勿将真实业务数据提交到公开仓库。

## 主要功能

- 院内记录规则筛选。
- 姓名与证件号匹配，支持中文姓名后缀兼容。
- 按疾病信号拆分主结果，适配一条记录包含多个病种提示的场景。
- 结合候选卡、报告时间和复诊周期生成辅助判定。
- 输出已报告/合规候选、可疑漏报、候选卡明细和文本统计报告。
- 对卡片 ID、疾病信号序号等字段做 Excel 文本保护。

## 当前版本

当前推荐版本：`CheckMiss-v10.1.6.py`

如 Python 环境异常，可运行 `一键卸载依赖库.py` 后重新启动主程序。
